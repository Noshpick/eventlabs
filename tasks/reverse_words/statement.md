# Reverse Words

Implement in `solution.py`:

```python
def reverse_words(s: str) -> str:
    ...
```

Return the input string with the order of the words reversed. Words are runs of
non-space characters. The result must contain single spaces between words and no
leading or trailing spaces.

- `reverse_words("hello world")` -> `"world hello"`
- `reverse_words("  a  b  ")` -> `"b a"`
