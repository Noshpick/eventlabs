# Valid Parentheses

Implement in `solution.py`:

```python
def valid_parentheses(s: str) -> bool:
    ...
```

Return `True` if every opening bracket `()`, `[]`, `{}` is closed in the correct
order by the matching closing bracket.

- `valid_parentheses("()[]{}")` -> `True`
- `valid_parentheses("([)]")` -> `False`
