# Maximum Subarray

Implement in `solution.py`:

```python
def max_subarray(nums: list[int]) -> int:
    ...
```

Return the largest sum of any contiguous non-empty subarray.

- `max_subarray([-2, 1, -3, 4, -1, 2, 1, -5, 4])` -> `6` (subarray `[4, -1, 2, 1]`)
- `1 <= len(nums) <= 10**5` — aim for O(n).
