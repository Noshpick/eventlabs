# Missing Number

Implement in `solution.py`:

```python
def missing_number(nums: list[int]) -> int:
    ...
```

`nums` contains `n` distinct numbers taken from the range `0..n`. Return the one
number from the range that is missing.

- `missing_number([3, 0, 1])` -> `2`
- Aim for O(n) time and O(1) extra space.
