# Two Sum

Implement in `solution.py`:

```python
def two_sum(nums: list[int], target: int) -> tuple[int, int]:
    ...
```

Return the **indices** `(i, j)` with `i < j` such that `nums[i] + nums[j] == target`.

- Exactly one solution exists for every test input.
- `2 <= len(nums) <= 10**4`, values fit in 32-bit integers.
- Aim for better than O(n²) — hidden tests include large inputs.
