# Rotate Array

Implement in `solution.py`:

```python
def rotate_array(nums: list[int], k: int) -> list[int]:
    ...
```

Return a new list equal to `nums` rotated to the right by `k` positions. `k` may
be larger than the length of the list. Do not modify the input.

- `rotate_array([1, 2, 3, 4, 5, 6, 7], 3)` -> `[5, 6, 7, 1, 2, 3, 4]`
