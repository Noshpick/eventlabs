# Min Stack

Implement in `solution.py` a class:

```python
class MinStack:
    def push(self, val: int) -> None: ...
    def pop(self) -> None: ...
    def top(self) -> int: ...
    def get_min(self) -> int: ...
```

All four operations must work in O(1) time. `get_min` returns the minimum
element currently in the stack.
