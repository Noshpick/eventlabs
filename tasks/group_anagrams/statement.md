# Group Anagrams

Implement in `solution.py`:

```python
def group_anagrams(strs: list[str]) -> list[list[str]]:
    ...
```

Group words that are anagrams of each other. Every input word must appear in
exactly one group. Group order and order inside a group do not matter.

- `group_anagrams(["eat", "tea", "tan", "ate", "nat", "bat"])` -> three groups:
  `["eat", "tea", "ate"]`, `["tan", "nat"]`, `["bat"]`
